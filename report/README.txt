How to compile this report (Overleaf)
=====================================

1. Go to overleaf.com -> New Project -> Upload Project.
2. Zip this whole folder (report.tex + figs/) and upload the zip,
   OR upload report.tex and the figs/ folder keeping the structure.
3. Set the main document to report.tex.
4. Compiler: pdfLaTeX (default). Click Recompile.

Output is a ~4-page IEEE two-column PDF.

Files
-----
report.tex          the report source (IEEEtran, conference style)
figs/               the six figures it includes
